САПЁР / ARENA

Сборка
1. Установите Python 3 и PyInstaller: py -m pip install pyinstaller
2. Запустите build_game.bat: dist\Saper.exe.
3. Запустите build_installer.bat: dist\SaperInstaller.exe.

Самый простой способ раздать игру
Файл dist\Saper.exe уже содержит и игру, и сервер комнат. Если он меньше
лимита вашего Discord, отправьте друзьям только этот файл. Им не нужны Python,
установщик или отдельный серверный .exe.

Публикация через GitHub (необязательно)
1. Создайте GitHub-репозиторий и откройте Releases -> Create a new release.
2. Загрузите dist\Saper.exe в Assets релиза и опубликуйте релиз.
3. Отправьте друзьям dist\SaperInstaller.exe.
4. В загрузчике вставьте ссылку на репозиторий или релиз, например:
   https://github.com/OWNER/REPOSITORY/releases/latest
   Можно также вставить прямую ссылку на .exe из Assets.

Загрузчик получает файл напрямую из GitHub Releases потоками, без ограничения
20 МБ. Для обычной установки подходит Saper.exe; ZIP с игрой тоже поддерживается.

Онлайн-игра через Radmin VPN
1. Все игроки подключаются к одной сети/комнате Radmin VPN и запускают Saper.exe.
2. Хост нажимает ОНЛАЙН, вводит свой Radmin-IP и порт 4444, затем нажимает
   СОЗДАТЬ КОМНАТУ. Игра автоматически запускает сервер на компьютере хоста.
3. Хост отправляет друзьям свой Radmin-IP и шестизначный код комнаты.
4. Друзья вводят тот же Radmin-IP, порт 4444 и код, затем нажимают
   ВОЙТИ ПО КОДУ. Комната рассчитана максимум на четырёх игроков.
5. Не закрывайте игру хоста до конца партии. Разрешите входящие подключения
   TCP-порта 4444 в брандмауэре Windows для сети Radmin VPN.
   Проброс порта на роутере не нужен.

Адрес 127.0.0.1 работает только на компьютере хоста, его нельзя отправлять друзьям.

В онлайн-протоколе каждое чтение и запись ограничены порциями не более 1 КиБ;
TCP сам может объединять эти порции в сетевые пакеты другого размера.
Протокол не шифруется и не использует учётные записи, поэтому запускайте его
только на сервере и в сети, которым доверяете.

Режимы игры
- 1–4 игрока на одном компьютере по очереди или через онлайн-комнату.
- Шесть готовых размеров: 8, 12, 16, 24, 32 и 48 клеток.
- Свой размер от 8x8 до 48x48 и восемь цветовых тем.
- В командной игре безопасное открытие приносит очки, попадание на мину
  отнимает жизнь и два очка. У каждого игрока три жизни.
